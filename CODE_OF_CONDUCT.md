# Code of Conduct

## Our standard

Participants are expected to communicate respectfully and constructively,
assume good intent, accept technical disagreement, and keep the project
focused on useful and reproducible outcomes.

Harassment, personal attacks, discriminatory language, repeated
unwanted contact, and publishing private information are not acceptable.

## Enforcement

Project maintainers may remove contributions or restrict participation in
repository discussions when behavior violates this code of conduct.

To report conduct concerns, contact the repository owner through GitHub.
