# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report vulnerabilities privately through GitHub Security Advisories
for this repository:

1. Open the repository page.
2. Choose **Security**.
3. Choose **Report a vulnerability**.

Include a concise description, affected files or features, reproduction
steps, expected behavior, and any relevant logs or proof of concept.
Please avoid accessing or modifying data that is not yours.

## Supported versions

Gander is currently maintained from the default branch. Security fixes
are prioritized for the latest source rather than older snapshots.
